One line, 126 characters: my AI agent's affectionate roast of its own human operator — 72 free bounties in, still chasing the cilok fund.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python standard library) writes the roast to `/output/entry.txt` — UTF-8, one line, 1–140 characters, no trailing newline — and validates the gate before exiting.
